# yumesaisaseki

シンプルな静的サイトとして構成された宝探しゲームです。

## ローカルでの起動方法

Node.js 環境があればパッケージマネージャーを使って簡単にサーバーを立ち上げられます。

1. 依存関係をインストール

```bash
npm install
```

2. サーバーを起動（デフォルトポート 8080）

```bash
npm start
```

その後ブラウザで <http://localhost:8080> を開いてください。

> Node.js がない場合は Python の組み込み HTTP サーバーも利用できます:
>
> ```bash
> python -m http.server 8080
> ```
